## How StationPlaylist Studio Sits

StationPlaylist Studio does not replace the recorder, the console, or the clock you already operate. It sits beside them as a named studio clock for one job: which scheduler hour is live, which voice track still matches playout, and what the next person should read before the next hour.

If two people share a studio PC, each keeps a StationPlaylist Studio style of their own. Extra clocks wait for their own title instead of crowding the live scheduler.

A first visit should be one short voice track, then the same StationPlaylist Studio clock the next day. That is enough to see if the scheduler holds.

## Traffic Light

| Signal | On the StationPlaylist Studio board | What you do |

| Amber | Two hours mixed in one scheduler | Split the set before you air |
| Red | No title, no note, voice tracks unlabeled | Stop and name the clock first |
| Clear | Handoff written, live tracks few | Close StationPlaylist Studio and leave the desk |

## Open Order

1. Open the last StationPlaylist Studio scheduler, not a new empty clock.
2. Read the voice track list and the last handoff.
3. Finish one visible playout hour inside StationPlaylist Studio.
4. Write what changed, then close with fewer unlabeled voice tracks than you found.
5. If the set feels crowded, drop anything that belongs to a different StationPlaylist Studio hour.

## After a Week

A week in StationPlaylist Studio is not a separate recorder beside the clock. It is the same title, a shorter live voice list, and a note that still makes sense before the next hour. Take finished clocks off the live set so the next visit starts on the scheduler that is still open.

## Sign-off

- [ ] The StationPlaylist Studio workspace name is short enough to scan
- [ ] Only live voice tracks are on the board
- [ ] A second person can read the handoff
- [ ] The last StationPlaylist Studio clock still opens after a restart
- [ ] Finished hours are off the live StationPlaylist Studio set

## Field Note

StationPlaylist Studio is easier to trust when the clock stays smaller than the recorder folder it came from. Name the hour, keep the live scheduler, finish one visible voice track, and write what changed.

The same loop fits a night clock, a shared studio PC, or a station you operate. Open the last StationPlaylist Studio scheduler and continue. Do not rebuild the hour from scratch.
